## 동작

- 접속한 날짜로 임신 주수·D-Day·진행률·태아 크기 비유를 자동 계산합니다 (기준: 2027-04-12 = 40주 0일, 280일).
- 체크 상태는 Firebase Realtime Database(`tosil_story/state/checks`)로 두 폰이 실시간 공유하고, `localStorage`는 오프라인 캐시로 함께 씁니다. 메모·이름·선물 기록은 이 기기에만 저장됩니다.
- 파일만 있으면 동작합니다(빌드 없음). `index.html`을 열면 되고, GitHub Pages는 main 브랜치 루트를 그대로 씁니다.

## 실시간 동기화 (Firebase)

- 프로젝트: `tosil-story` · Realtime Database URL: `https://tosil-story-default-rtdb.firebaseio.com`
- 경로: `tosil_story/state/checks` (체크된 항목 id만 `true`로 저장)
- 인증 없이 읽고 쓰므로, 테스트 모드 규칙이 만료되면 Firebase 콘솔 → Realtime Database → 규칙에서 아래처럼 열어 두면 됩니다.

```json
{
  "rules": {
    "tosil_story": {
      ".read": true,
      ".write": true
    }
  }
}
```

- 이 규칙은 링크를 아는 사람이면 누구나 읽고 쓸 수 있다는 뜻이에요. 페이지는 `noindex`이고 메인 포털 잠금을 거쳐 들어오니 가족용으로만 공유하세요.

## 수정할 때

- `index.html`의 `styles.css?v=`, `app.js?v=` 쿼리를 함께 올리면 캐시가 갱신됩니다.
