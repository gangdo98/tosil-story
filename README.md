## 구성

| 탭 | 내용 |
| --- | --- |
| 📸 사진 | 주수별 초음파 타임라인(빈 상태) · 한 줄 성장 기록 |
| 🛒 살 것 | 후쿠오카 구매 4종(트립트랩·드래곤플라이 플러스·싸이벡스 카시트·아티포페) + 신생아 준비물 체크리스트, 대분류·상태 필터 |
| ✅ 할 일 | 중기(20~27주) / 후기(28~36주) / 막달(37~40주) / 출산 직후 체크리스트 |
| 🏥 병원 | 주수별 필수 검사 안내 · 다음 검진 카드 · 검진 메모(자동 저장) |
| 💰 지원금 | 첫만남이용권·부모급여·아동수당·부산형 산후조리비·진료비·배우자 출산전후휴가 + 6+6 육아휴직 플랜 |
| 🎒 가방 | 산모 / 아기 / 아빠 / 서류 체크리스트 |
| ✏️ 이름 | 이름 후보 · 선물 기록 |

## 동작

- 접속한 날짜로 임신 주수·D-Day·진행률·태아 크기 비유를 자동 계산합니다 (기준: 2027-04-12 = 40주 0일, 280일).
- 체크 상태·메모·이름·선물 기록은 `localStorage`에 기기에만 저장됩니다.
- 파일만 있으면 동작합니다(빌드 없음). `index.html`을 열면 되고, GitHub Pages는 main 브랜치 루트를 그대로 씁니다.

## 수정할 때

- 내용은 `app.js`의 데이터 블록(`SIZE`, `FUKUOKA`, `ESSENTIALS`, `TASK_STAGES`, `EXAMS`, `MONEY`, `BAG`)만 고치면 됩니다.
- `index.html`의 `styles.css?v=`, `app.js?v=` 쿼리를 함께 올리면 캐시가 갱신됩니다.
